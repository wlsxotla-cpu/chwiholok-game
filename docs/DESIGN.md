# 설계 문서 (DESIGN)

> 이 문서는 "무엇을 만드는가"를 정의합니다. 초기 기획서이며, 거의 고치지 않습니다.
> 자율 루프는 매 바퀴 이 문서를 읽고 전체 방향을 확인합니다.

## 한 줄 요약

취호록 — 뱀파이어 서바이벌(Vampire Survivors)과 유사한 무협 액션 로그라이크.
몰려오는 적 사이에서 무공을 자동으로 휘두르며 무한 생존한다.

## 핵심 목표

- **뱀파이어 서바이벌급 완성도.** 조작감, 타격감, 성장 곡선, 콘텐츠 밀도가 그
  기준에 뒤지지 않아야 한다. "돌아가기만 하는" 수준에서 멈추지 않는다.
- **다른 사람이 처음 봐도 퀄리티가 떨어지지 않아야 한다.** 판정 범위와 이펙트가
  정확히 일치하는지, 글자 크기·UI 배치가 자연스러운지, 사운드가 상황에 맞는지까지
  세부적으로 다듬는다. 이게 이 프로젝트의 합격 기준이다 (`loop/PROMPT.md` ① 참고).
- **모바일(터치) 우선.** 실제 휴대폰 브라우저에서 플레이하는 걸 기준으로 만든다.
  PC 키보드 조작은 보조 수단이다.

## 타겟 플랫폼 / 기술 스택

- Godot 4.7 (GDScript)
- Web(HTML5/WASM) export, 모바일 브라우저에서 설치 없이 플레이
- 가상 조이스틱 기반 터치 컨트롤

## 범위 (이번 프로젝트가 다루는 것)

- **캐릭터**: 5종 플레이 가능(이포폴/정형/이경/성주창/심장법사) + 출시 예정 1종
  (응두니, 아직 미구현). 캐릭터마다 시그니처 무기 하나로 시작.
- **무기**: 9종 (회전베기/호신강기/관통시/화염구 장판/표창난사/어검비행/회류표/
  일자검기/뇌전장). 레벨업으로 성장(최대 8레벨) → 만렙+전용 비급으로 진화 →
  서로 다른 무기 2개를 각각 만렙 찍으면 융합해서 더 강한 새 무기가 된다
  (융합 결과물은 4종: 천지개벽검/멸겁관천검/선풍만리표/뇌검진).
- **비급(패시브)**: 5종 (파산도결/철갑신공/비연신법/연격지결/채기흡자결). 무기
  전용이 아니라 스탯 타입별 범용 아이템이며, 하나가 여러 무기의 진화 조건을
  동시에 만족시킬 수 있다. 최대 5칸.
- **적**: 기본 4종(그런트/브루트/아처/봄버) + 쾌검수. 일반 보스(2분 30초마다,
  반복 등장할수록 강해짐), 몬스터 웨이브(50초마다 대량 스폰), 30분 시점
  1회성 최종보스(천마/오버로드).
- **난이도**: 하드모드 토글 (캐릭터 선택 화면에서 선택). 시간 경과에 따라
  스폰 속도·적 강도가 계속 증가하는 무한 생존 구조.
- **메타 진행**: 몹 처치로 내공(재화) 획득 → 캐릭터 해금, 영구 스탯 강화 구매.
- **월드**: 정사각형 경계(벽)가 있는 맵, 벽은 빛나는 결계로 표현. HD-2D풍
  조명(플레이어 랜턴 + 바닥 텍스처)과 배경 아트.
- **연출/사운드**: 레벨업/진화/융합/보스 등장 시 배너 연출, SFX 전반, BGM.

## 범위 밖 (하지 않는 것)

- 멀티플레이어 / PvP
- 인앱 결제, 실제 과금
- 스토리 모드, 컷씬
- 네이티브 앱 빌드(iOS/Android 스토어 출시) — 지금은 웹 브라우저 플레이까지만
